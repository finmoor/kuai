# 各家命令行工具的图标

新建终端的预设里用来认出是哪个工具。都是单色的形状，画的时候按需要的颜色填。商标归各自的所有者，这里只用来标明按钮开的是哪个工具。

| 文件 | 工具 | 出处 |
|---|---|---|
| `claude-code.svg` | Claude Code | [Simple Icons](https://simpleicons.org) 16.38.1 的 `claudecode`（取自 code.claude.com） |
| `openai.svg` | Codex | Simple Icons 13.0.0 的 `openai`（取自 openai.com）；Codex 的官方页面用的就是这个标志 |
| `opencode.svg` | OpenCode | Simple Icons 16.38.1 的 `opencode`（取自 OpenCode 仓库的 `packages/identity/mark.svg`） |
| `antigravity.svg` | Antigravity CLI | antigravity.google 的 `favicon.svg` 里那条拱形轮廓（去掉了彩色渐变） |
