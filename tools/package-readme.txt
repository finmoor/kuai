Kuai（筷子）
============

Windows 上的 Git 客户端，界面和操作方式接近 Fork，可以直接打开服务器上的仓库。

使用方法
--------
1. 安装版：安装完成后从开始菜单打开 Kuai。解压版：双击 kuai.exe 即可运行，文件夹可放在任意位置
   （kuaid 文件夹须与 kuai.exe 位于同一目录）。
2. 「服务器」页（标题栏最左侧）：左侧列出本机和已配置的服务器，选中一台后右侧显示其状态和其中的仓库。
   - 选中「本机」后点击「添加本机仓库…」：填写仓库路径。也可以在命令行中运行 kuai.exe <仓库路径> 直接打开。
   - 「添加服务器…」（左侧列表底部）：填写主机（IP、主机名或 ~/.ssh/config 中的主机别名）、端口和用户名；
     登录方式选择密钥（可指定私钥文件及其口令，留空则使用默认密钥和 ssh-agent）或密码。
     填写的密码和私钥口令保存在 Windows 凭据管理器中，之后连接无需再次输入；留空则在连接时弹窗输入。
     只能经由另一台服务器访问时，在「跳板机」中从已配置的服务器里选择（跳板机自身也可以再经由一台）；
     连接时依次登录，跳板机上不安装任何程序。
     首次连接时，会将 kuaid 文件夹中的程序上传到服务器的 ~/.kuai/ 下并启动，不需要 root 权限，也不开放网络端口。
     kuaid 在服务器上常驻运行；所有客户端断开且终端全部结束 10 分钟后自动退出，下次连接时重新启动。
     服务器可以是 Linux，也可以是开启了 OpenSSH 服务的 Windows 电脑（64 位，Windows 10 1803 及以上），
     连接时自动识别。Windows 上的 kuaid 只监听本机回环地址，凭保存在用户目录中的口令连接。
     之后选中该服务器，点击「打开仓库…」，在服务器上选择目录；勾选标有「仓库」的目录可一次打开多个，切换目录后已勾选的仍保留。
     连接后，该服务器上配置的其他服务器缩进列在其下方，标注「经由 <服务器名>」：由该服务器代为连接，本机无需配置；
     这类服务器上的仓库不支持外部终端、VS Code 和目录映射，连接设置需在该服务器上修改。
     其中与本机或本机已配置的服务器是同一台电脑的，认出后不再重复列出。
   - 点击仓库即在标签页中打开；仓库中的子仓库默认收起，点击左侧的箭头展开。
     仓库可以设置显示名称：鼠标悬停在仓库行上点击铅笔图标，或在标签页、侧栏顶部的仓库名上右键选择「重命名…」。
     仅修改显示名称，不改动目录。名称保存在仓库所在的电脑上，连接该电脑的所有电脑同步显示。
3. 仓库页：左侧为本地修改、所有提交、分支、远程、标签、贮藏；
   分支、远程分支和标签按名称中的 / 分组为文件夹，可在上方的输入框中过滤；
   在本地修改中可按文件、按块或按行暂存和丢弃，填写说明后提交
   （提交按钮右侧的箭头中有「提交并推送」，说明框上方有「最近使用」）；
   改动区域右上角的两个按钮分别为显示整个文件、并排显示；
   工具栏上有获取、拉取、推送、贮藏、新建分支和活动（已执行的 git 命令及输出）。
   各栏之间的分隔条可以拖动，双击恢复默认宽度。
   左侧栏可以收起为一列图标：点击侧栏右上角的按钮、按 Ctrl+Shift+B，或将侧栏的分隔条拖到最左侧。
   收起后点击分支、远程、标签、贮藏的图标，可在弹出的列表中选择；切换分支、删除等操作需展开侧栏。
   再次按 Ctrl+Shift+B 或点击左下角的按钮即可展开。所有标签页共用收起状态，重新打开 Kuai 后保持不变。
4. 大部分操作位于右键菜单中：
   - 提交的右键菜单：检出、新建分支和标签、挑拣、还原、重置、变基、
     交互式变基（整理此后的提交：调整顺序、修改说明、并入、丢弃）。
   - 分支的右键菜单：切换、合并（可选择不快进、压缩合并、合并后暂不提交）、变基、拉取、推送、
     强制推送、重命名、删除，以及「在提交列表中仅显示此项」「在提交列表中隐藏」。
     提交列表右上角可切换「所有分支」「仅当前分支（及其上游）」，已隐藏的分支也在此处取消隐藏。
   - 文件的右键菜单：暂存、丢弃、添加到 .gitignore、用默认程序打开、文件历史、逐行追溯。
     没有改动的文件：在「所有提交」中点击右上角的「文件历史…」选择文件。
   - 工具栏上的获取、拉取、推送：右键菜单中有更多选项。
   合并或变基遇到冲突时，工具栏下方会显示提示横幅。在「本地修改」中选中有冲突的文件，
   点击「解决冲突…」：每处冲突可选择当前分支的版本、传入的版本或保留双方，也可以切换到「手动编辑」直接修改，
   保存后该文件即标记为已解决。全部解决后点击「继续」（合并时为「提交合并」），如需放弃请点击「中止」。
   有未提交的改动时切换分支、检出或拉取，会先询问处理方式：保留改动并切换，或先贮藏、完成后恢复。
5. 在「服务器」页中选中本机或一台服务器，点击「克隆…」可将仓库克隆到该电脑上。
6. 右上角的齿轮（或 Ctrl+,）打开设置：界面语言（中文、English）、开机时自动启动、
   最小化到托盘、关闭窗口时最小化到托盘、颜色模式（新安装时默认为深色）、配色（13 套，点击色板即可切换）；
   终端的等宽字体、中文字体、字号、行高、光标样式、回滚行数、选中即复制、右键的作用（附预览，修改后立即生效）；
   自动获取的间隔（默认每 10 分钟在后台执行一次 git fetch，可关闭）、默认先贮藏未提交的改动。
7. 标题栏：最左侧为「服务器」「终端」「工作区」三个页面（窗口较窄时只显示图标），随后是仓库的标签页和
   「+」（快速打开，Ctrl+P）；终端的标签页排在右侧、齿轮之前。
   - 标签页与工作区无关：从服务器页、工作区页、终端页或快速打开中打开的仓库和终端，都加入这一排标签页，
     已打开的直接切换过去。打开、关闭标签页不会改变工作区。
   - 标签页右键菜单中有「固定标签页」（排在最前，取消固定后才能关闭）、关闭其他、关闭右侧、全部关闭、
     重新打开已关闭的标签页、「在工作区页中显示」、「重命名…」和「复制仓库路径」；鼠标中键关闭标签页。
     标签页较多时会变窄，放不下的收进「⌄ N」，点击可列出全部标签页。
   - 「工作区」页：工作区是一组常一起查看的仓库（例如「公司」「个人」）。左侧选择服务器和其中的工作区，
     点击「新建工作区…」新建，右键可重命名、删除；右侧列出所选工作区中的仓库及其子仓库，以及各自的分支和改动数。
     点击仓库或子仓库即在标签页中打开；「全部打开」将其中的仓库连同子仓库都在标签页中打开；
     「添加仓库…」中勾选即加入此工作区；鼠标悬停在仓库行上可「新建终端」或「移出工作区」。
   - 仓库列表和工作区保存在各自所在的电脑上：本机的保存在本机，服务器上的保存在该服务器上。
     连接同一台服务器的所有电脑看到的是同一份，任何一台修改后，其他电脑立即同步。
     打开了哪些标签页只记录在本机。
   - 与服务器的连接断开时，其中的工作区和仓库列表只能查看，不能修改，Kuai 会自动重新连接。
   - 每台电脑至少保留一个工作区。
8. 显示不全的文字（路径、分支名、提交说明等），鼠标悬停时显示全文。
9. 每个仓库分为 Git、终端、文件三页：在侧栏仓库名下方切换；按 Ctrl+` 进入终端页，再按一次回到之前的那一页。
   进入终端页时不会自动打开终端，点击「打开终端」（或按 Ctrl+Shift+`）打开第一个。
   终端页中的终端以仓库目录为工作目录；切回 Git 页后，终端中的程序继续运行。
   一个仓库可以打开多个终端，均列在终端页的侧栏中：点击「新终端」（或按 Ctrl+Shift+`）再打开一个，
   点击一行即可切换，点击行尾的 × 结束终端；右键菜单中还有「发送图片或文件…」和「重启」。
   右侧上方的「发送文件」「重启」作用于当前选中的终端。
   - 本机仓库：终端运行在本机的 kuaid 中（首次使用时安装到 %USERPROFILE%\.kuai 下），关闭标签页、
     退出或更新 Kuai 后，其中的程序继续运行，再次进入该仓库的终端页即可接回，屏幕内容保持不变。
     如需结束，请点击侧栏中该行的 ×。使用的 shell 可在设置中选择。
     kuaid 无法启动（例如被安全软件拦截）时，终端改为运行在 Kuai 中：关闭标签页后仍继续运行，
     退出 Kuai 时结束（会先询问，启用托盘时也可改为最小化到托盘）。
     从其他电脑经 SSH 连接这台电脑时，看到的是同一批终端。
   - 服务器上的仓库：终端运行在服务器上，关闭标签页、退出 Kuai 或断线后，其中的程序继续运行
     （例如正在运行的 Claude Code）；再次进入该仓库的终端页即可重新连接，屏幕内容保持不变。
     如需结束，请点击侧栏中该行的 ×。断线时终端底部会显示提示，按 Enter 重新连接。
   - 「终端」后面的数字是正在运行的终端数量（关闭标签页后保留的该仓库终端也计算在内）。
   - 向终端中的程序（例如 Claude Code、Codex）发送图片或文件：拖放到终端中，或复制文件、截图后
     按 Ctrl+V，或点击「发送文件」选择。粘贴的是文件路径，由程序自行读取。
     服务器上的终端会先将文件上传到服务器的 ~/.kuai/drop/ 下（7 天后自动清理）。
   - 「终端」页（Ctrl+Shift+A）汇总所有工作区中各仓库的终端：侧栏按工作区列出仓库及其终端，右侧显示所选终端的画面，
     点击画面或按 → 即可输入；终端和仓库可以固定在顶部。终端停止输出时会提醒，
     Kuai 不在前台时发送 Windows 通知（可在设置中关闭）。
   - 终端也可以开成标签页，占满整个窗口：在「工作区」页的仓库行上点击「新建终端」，或在「终端」页中选中终端后按 Enter
     （「在标签页中打开」）。关闭终端标签页不会结束终端；如需结束，请在标签页的右键菜单中选择「结束终端…」。
   「打开」菜单中还有「在外部终端中打开」。
10. 文件页（Ctrl+Shift+E）：左侧为仓库的目录树，右侧为编辑器，用于查看和少量修改。
    单击文件为预览，双击则保留其标签；按 Ctrl+S 保存，文件已在别处被修改时会提示冲突。
    目录树的右键菜单中可新建、重命名、删除（本机文件移入回收站，服务器上的文件永久删除）和下载；
    将本机文件拖到目录树上，或点击「上传文件…」，即可上传到服务器上的仓库。
    图片直接显示；PDF、Word、Excel、视频等文件可用默认程序打开或下载（服务器上的文件先下载到本机临时目录）。
    服务器上的文件通过已建立的连接读写，无需另行配置 SFTP，使用跳板机时同样可用。
11. 子仓库和工作树：仓库目录中还有其他仓库时，侧栏显示「子仓库」；侧栏的「工作树」列出该仓库的全部工作树
    （包括 Claude Code、Codex 创建的）。点击后右侧为总览表，列出分支、改动数、与上游的差异和最近提交；
    点击其中一行即可在当前标签页中进入，Git、终端、文件三页均为该仓库的，点击侧栏顶部的「返回」或按 Alt+← 回到总览。
    在工作树总览中可新建工作树（默认位于仓库旁边的「<仓库名>.worktrees」文件夹中）、移除、清理目录已不存在的工作树；
    分支已在其他工作树中检出时，双击该分支可进入对应的工作树；分支的右键菜单中有「在新工作树中检出…」。
12. 目录映射：可将服务器上的目录映射为本机的盘符（如 K:）或文件夹，用资源管理器、编辑器等本机程序直接查看和修改。
    在服务器编辑对话框的「映射到本机」一节中添加，或在「服务器」页选中该服务器后，从「⋯」中选择「映射目录到本机…」；
    可设为连接服务器后自动映射，也可设为只读；映射为盘符时可设置名称，资源管理器中显示为「名称 (K:)」。
    「服务器」页中服务器名称旁的每条映射显示为一个标记，点击后可在资源管理器中打开、
    复制本机路径、断开、立即映射、修改设置或取消映射。仓库列表、文件页和状态栏中也显示对应的本机路径。
    映射使用该服务器已建立的连接，仅在 Kuai 运行期间可用（最小化到托盘时仍可用），退出 Kuai 时断开。
    在映射的目录中运行 git 或构建会很慢，请仍在 Kuai 或服务器上进行；服务器上由他人修改的文件最多 2 秒后可见。
    需安装 WinFsp；未安装时，点击「安装 WinFsp」即可经 winget 安装，没有 winget 时会打开 WinFsp 的下载页面。
    VS Code 中的部分功能（如 Copilot 智能体）会将映射的目录解析为 \\kuai\… 的网络路径，
    需在 VS Code 设置的 security.allowedUNCHosts 中添加 kuai。
13. 误关标签页时，按 Ctrl+Shift+T 重新打开；Ctrl+P 中最近关闭的标签页排在最前。
    常用的标签页可以固定；也可以在设置中隐藏标签页上的关闭按钮。
14. 更新：有新版本时，标题栏齿轮左侧显示「新版本 x.y.z」，点击可查看更新内容，点击「更新」开始下载，
    下载完成后点击「重启以完成更新」。服务器上和本机 kuaid 中的终端不受影响；有终端运行在 Kuai 中时会先询问。
    也可以在「设置 → 关于」中检查更新或关闭自动检查。解压版位于没有写入权限的文件夹（例如 Program Files）
    时无法自动更新，请前往 https://github.com/finmoor/kuai/releases 手动下载。
    服务器上的 kuaid 无需单独更新，新版 Kuai 连接时会自动替换。

快捷键
------
F5 刷新；Ctrl+Enter 提交；Ctrl+F 在当前页中查找（Git 页中搜索提交，文件页中查找打开的文件）；Ctrl+P 快速打开仓库；
Ctrl+1 本地修改；Ctrl+2 所有提交；
Ctrl+W 关闭标签页（也可用鼠标中键；在文件页中先关闭当前打开的文件）；Ctrl+Shift+T 重新打开已关闭的标签页；
Ctrl+Tab、Ctrl+Shift+Tab 切换标签页；Ctrl+, 设置；Ctrl+` 进入终端页，再按一次返回；
Ctrl+Shift+` 新建终端；Ctrl+Shift+E 文件页；Ctrl+S 保存文件页中打开的文件；Ctrl+Shift+B 收起、展开侧栏；
Ctrl+Shift+A 「终端」页；Alt+← 从子仓库或工作树返回总览。
终端中：仅 Ctrl+Tab、Ctrl+Shift+Tab、Ctrl+Shift+T、Ctrl+1、Ctrl+2、Ctrl+Shift+E、Ctrl+`、Ctrl+Shift+`、
Ctrl+,、Ctrl+Shift+B、Ctrl+Shift+A 仍由 Kuai 处理，其余按键（Tab、Esc、F5、Ctrl+W、Ctrl+F、Ctrl+P、Ctrl+S 等）均交给终端中的程序；
Ctrl+C 中断（选中文字时为复制）；Ctrl+Shift+C 复制；Ctrl+V、Shift+Insert 粘贴（粘贴图片或文件时为文件路径）；
右键默认在有选中文字时复制，否则粘贴（可在设置中修改）；Ctrl+加号、Ctrl+减号调整字号，Ctrl+0 恢复默认；
鼠标滚轮、触摸板或 Shift+PageUp、Shift+PageDown 查看之前的输出；终端中的程序使用鼠标时（例如 Claude Code），
滚轮交给程序，按住 Shift 滚动则查看终端的记录。
列表中：上下方向键切换选中项；在文件和改动行上按空格键暂存、按 Delete 丢弃；
文件列表中按住 Ctrl 或 Shift 点击可多选。
文件页的目录树中：方向键移动、折叠和展开，Enter 打开，空格键预览，F2 重命名，Delete 删除。

运行要求
--------
- PATH 中有 git（安装 Git for Windows 即可）。
- 连接服务器使用 Windows 自带的 OpenSSH（C:\Windows\System32\OpenSSH\ssh.exe），
  沿用 ~/.ssh/config 和密钥；未保存的密码或私钥口令在需要时弹窗输入。
- 服务器为 Linux 或开启了 OpenSSH 服务的 Windows，并已安装 git。
- 将服务器目录映射到本机时需安装 WinFsp（https://winfsp.dev/），未安装时 Kuai 可经 winget 代为安装。

其他
----
- 设置保存在 %APPDATA%\kuai\settings.json，不包含密码。服务器密码和私钥口令保存在
  Windows 凭据管理器中（控制面板 › 凭据管理器 › Windows 凭据 › 普通凭据，名称以 kuai:server: 开头），
  移除服务器时一并删除。
- 仓库列表和工作区保存在 %APPDATA%\kuai\workspaces.json（Linux 服务器上为 ~/.config/kuai/workspaces.json），
  由该电脑上的 kuaid 读写。从 1.13 及更早版本升级时，原来的仓库列表和工作区会自动迁移：
  本机的在启动时迁移，服务器上的在首次连接该服务器时并入其列表。
- 卸载安装版：在 Windows「设置 → 应用」中找到 Kuai 并卸载。开机自动启动会一并清除；如保存了服务器密码，
  会询问是否删除；设置文件会保留，如不再需要，请删除上述文件夹。
- 卸载解压版：先在设置中关闭「开机时自动启动」，移除保存了密码的服务器，然后删除此文件夹和上述设置文件。
- 服务器上：先运行 ~/.kuai/*/kuaid --stop（结束终端并退出常驻进程），然后删除 ~/.kuai。
- 查看服务器上的常驻进程和终端：~/.kuai/*/kuaid --status；日志位于 ~/.kuai/run/kuaid.log。
- kuaid\x86_64-pc-windows-msvc 中的 conpty.dll、OpenConsole.exe 是微软 Windows Terminal 项目发布的
  新版 ConPTY（MIT 许可），供 Windows 上的终端使用。
- 本机和 Windows 服务器上的 kuaid 位于 %USERPROFILE%\.kuai 下，用法相同：在命令行中运行其中的
  kuaid.exe --status 或 kuaid.exe --stop。卸载 Kuai 不会结束其中的终端，也不会删除此文件夹；
  如不再需要，请先运行 kuaid.exe --stop，然后删除此文件夹。
- 解压版移动位置后，需重新开启「开机时自动启动」（启动项中记录的是原来的路径）。
- 查看日志：在命令行中设置环境变量 FR_LOG=1，并将标准错误重定向到文件，例如
    set FR_LOG=1 && kuai.exe 2> log.txt
