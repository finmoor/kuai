fork-remote（暂名）
==================

Windows 上的 Git 客户端，界面和操作习惯接近 Fork，能直接打开服务器上的仓库。

怎么用
------
1. 双击 fork-remote.exe。不用安装，整个文件夹放哪都行（agents 文件夹要和 exe 在一起）。
2. 「仓库」标签页里：
   - 「添加本机仓库」：填仓库路径。也可以在命令行里 fork-remote.exe <仓库路径> 直接打开。
   - 「添加服务器」：填 ssh 目标（~/.ssh/config 里的主机别名，或者 user@host）。
     第一次连接会把 agents 里的程序上传到服务器的 ~/.fork-remote/ 下，不要 root、不开端口。
     然后「浏览」服务器上的目录，打开仓库。
3. 仓库页：左边是本地修改、所有提交、分支、远程、标签、贮藏；
   分支、远程分支、标签按名字里的 / 排成文件夹，上面的框可以过滤；
   本地修改里可以按文件、按块、按行暂存和丢弃，写说明后提交；
   工具栏上有获取、拉取、推送、贮藏、新建分支。
4. 大部分操作在右键菜单里：
   - 提交上点右键：检出、新建分支和标签、挑拣、还原、重置、变基。
   - 分支上点右键：切换、合并、变基、推送、强制推送、改名、删除。
   - 文件上点右键：暂存、丢弃、加到 .gitignore、用编辑器打开、文件历史、逐行追溯。
     没有改动的文件：在「所有提交」里点右上角的「文件历史…」选文件。
   - 工具栏的获取、拉取、推送上点右键：有不常用的选项。
   合并、变基遇到冲突时，工具栏下面会出现一条横幅，解决后点「继续」（合并时叫「提交合并」），不想做了点「中止」。
5. 「仓库」标签页里每组右边的「克隆…」可以克隆到本机或服务器。
6. 右上角的齿轮（或 Ctrl+,）是设置：界面语言（中文、English）、开机时自动启动、
   最小化时收到托盘、关闭窗口时收到托盘、深色还是浅色、配色（13 套，点小样就换）。
7. 左上角的按钮是工作区：一个工作区是一组标签页，可以新建几个（比如「公司」「个人」）来回切；
   标签页上点右键可以把它移到别的工作区。

快捷键
------
F5 刷新；Ctrl+Enter 提交；Ctrl+F 搜索提交；Ctrl+P 快速打开仓库；
Ctrl+1 本地修改；Ctrl+2 所有提交；
Ctrl+W 关标签页（鼠标中键也行）；Ctrl+Tab、Ctrl+Shift+Tab 切标签页；Ctrl+, 设置。
列表里：上下键换选中的项；文件和改动行上空格暂存、Delete 丢弃；
文件列表里 Ctrl、Shift 加点击可以多选。

需要
----
- git 在 PATH 里（装了 Git for Windows 就有）。
- 连服务器用的是 Windows 自带的 OpenSSH（C:\Windows\System32\OpenSSH\ssh.exe），
  沿用 ~/.ssh/config 和密钥；要密码或密钥口令时程序会弹窗问。
- 服务器是 Linux，装了 git。

其他
----
- 设置存在 %APPDATA%\fork-remote\settings.json，不存密码。
- 卸载：先在设置里把「开机时自动启动」关掉，再删掉这个文件夹和上面的设置文件；服务器上删掉 ~/.fork-remote。
- 程序挪了位置以后，「开机时自动启动」要重新开一次（启动项里记的是原来的路径）。
- 看日志：在命令行里先设环境变量 FR_LOG=1，再把标准错误重定向到文件，比如
    set FR_LOG=1 && fork-remote.exe 2> log.txt
