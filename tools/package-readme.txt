Kuai（筷子）
============

Windows 上的 Git 客户端，界面和操作习惯接近 Fork，能直接打开服务器上的仓库。

怎么用
------
1. 双击 kuai.exe。不用安装，整个文件夹放哪都行（kuaid 文件夹要和 exe 在一起）。
2. 「仓库」标签页里（下面这几样都在「全部仓库」下面，收着的话点一下展开）：
   - 「添加本机仓库」：填仓库路径。也可以在命令行里 kuai.exe <仓库路径> 直接打开。
   - 「添加服务器」：填主机（IP、主机名，或 ~/.ssh/config 里的主机别名）、端口、用户名，
     登录方式选密钥（可以指定私钥文件和它的口令，不填就用默认密钥和 ssh-agent）或密码。
     填了的密码、口令存在 Windows 凭据管理器，以后连接不用再输；不填就在连接时弹窗问。
     第一次连接会把 kuaid 文件夹里的程序上传到服务器的 ~/.kuai/ 下并启动，不要 root、不开网络端口。
     它在服务器上常驻；客户端都断开、终端也都结束了，10 分钟后自己退出，下次连接再起来。
     然后「打开仓库…」在服务器上挑目录。
   - 仓库可以另起一个显示的名字：行尾的铅笔，或者在标签页、侧栏顶上的仓库名上点右键选「改名…」。
     只改显示，不动目录。
3. 仓库页：左边是本地修改、所有提交、分支、远程、标签、贮藏；
   分支、远程分支、标签按名字里的 / 排成文件夹，上面的框可以过滤；
   本地修改里可以按文件、按块、按行暂存和丢弃，写说明后提交
   （提交按钮右边的小箭头里有「提交并推送」，说明框上面有「最近用过的」）；
   改动右上角的两个小按钮：显示整个文件、并排着看；
   工具栏上有获取、拉取、推送、贮藏、新建分支、活动（执行过的 git 命令和输出）。
   各栏之间的分隔条可以拖，双击回到默认大小。
4. 大部分操作在右键菜单里：
   - 提交上点右键：检出、新建分支和标签、挑拣、还原、重置、变基、
     交互式变基（整理它之后的提交：调顺序、改说明、并入、丢弃）。
   - 分支上点右键：切换、合并（可以选不快进、压缩、先不提交）、变基、拉取、推送、强制推送、
     改名、删除；「提交列表里只看它」「在提交列表里隐藏」。
     提交列表右上角可以切「所有分支」「只看当前分支」，隐藏的也在那里取消。
   - 文件上点右键：暂存、丢弃、加到 .gitignore、用编辑器打开、文件历史、逐行追溯。
     没有改动的文件：在「所有提交」里点右上角的「文件历史…」选文件。
   - 工具栏的获取、拉取、推送上点右键：有不常用的选项。
   合并、变基遇到冲突时，工具栏下面会出现一条横幅。在「本地修改」里选中有冲突的文件，
   点「解决冲突…」：每一处冲突选用当前的、传入的或者两边都留，也可以切到「手动编辑」自己改，
   保存后这个文件就算解决了。都解决后点「继续」（合并时叫「提交合并」），不想做了点「中止」。
   工作区有没提交的改动时切换分支、检出、拉取，会先问：带着改动做，还是先贮藏、做完再放回来。
5. 「仓库」标签页里每组右边的「克隆…」可以克隆到本机或服务器。
6. 右上角的齿轮（或 Ctrl+,）是设置：界面语言（中文、English）、开机时自动启动、
   最小化时收到托盘、关闭窗口时收到托盘、深色还是浅色、配色（13 套，点小样就换）；
   自动获取的间隔（默认每 10 分钟在后台 git fetch 一次，可以关）、有改动时切换分支默认先不先贮藏。
7. 左上角的按钮是工作区，可以新建几个（比如「公司」「个人」）来回切。
   在哪个工作区里打开过的仓库就归它：「仓库」页最上面先列这些仓库，开着的、没开的分开，
   手滑关了就在这里找；别的仓库在下面的「全部仓库」里。
   关标签页不会把仓库移出工作区，要移出就点行尾的按钮，或者标签页右键的「从工作区移除」。
   标签页右键还有「固定标签页」（排到最前，关不掉，取消固定才能关）和移到别的工作区。
   标签页多了会变窄，再多就在标签栏上滚滚轮，或者点 + 右边的小箭头从列表里挑。
8. 放不下被截掉的文字（路径、分支名、提交说明……），鼠标停上去显示全文。
9. 工具栏的「终端」（或 Ctrl+`）在仓库页底下开一个终端，已经在仓库目录里。
   上边可以拖高矮，右上角三个按钮是重新启动、结束、收起；收起以后里面的程序接着跑。
   - 本机仓库：关标签页时终端里的程序跟着结束（会先问）。用哪个 shell 在设置里选。
   - 服务器上的仓库：终端开在服务器上，关标签页、退出 Kuai、断线，里面的程序都接着跑
     （比如跑到一半的 Claude Code）；再打开这个仓库的终端就接上，屏幕还是原来的样子。
     要结束它点右上角的「结束」。断线时终端底下会提示，按回车重新接上。
   - 面板收着、里面有东西在跑时（或者服务器上留着这个仓库的终端），「终端」按钮上有个 1。
   「打开」里还有「在外部终端里打开」。
10. 手滑关了标签页：Ctrl+Shift+T 重新打开，Ctrl+P 里刚关掉的排最前；
    常用的可以固定；怕手滑还可以在设置里把标签页上的关闭按钮藏起来。

快捷键
------
F5 刷新；Ctrl+Enter 提交；Ctrl+F 搜索提交；Ctrl+P 快速打开仓库；
Ctrl+1 本地修改；Ctrl+2 所有提交；
Ctrl+W 关标签页（鼠标中键也行）；Ctrl+Shift+T 重新打开刚关掉的；
Ctrl+Tab、Ctrl+Shift+Tab 切标签页；Ctrl+, 设置；Ctrl+` 终端。
终端里：Ctrl+C 中断（选着字时是复制）；Ctrl+V 粘贴；右键是选着字就复制、没选就粘贴；
滚轮和 Shift+PageUp、PageDown 翻前面的输出。
列表里：上下键换选中的项；文件和改动行上空格暂存、Delete 丢弃；
文件列表里 Ctrl、Shift 加点击可以多选。

需要
----
- git 在 PATH 里（装了 Git for Windows 就有）。
- 连服务器用的是 Windows 自带的 OpenSSH（C:\Windows\System32\OpenSSH\ssh.exe），
  沿用 ~/.ssh/config 和密钥；没存的密码或密钥口令，要用时程序会弹窗问。
- 服务器是 Linux，装了 git。

其他
----
- 设置存在 %APPDATA%\kuai\settings.json，不存密码。服务器的密码、私钥口令存在
  Windows 凭据管理器（控制面板 › 凭据管理器 › Windows 凭据 › 普通凭据，名字以 kuai:server: 开头），
  移除服务器时跟着删掉。
- 卸载：先在设置里把「开机时自动启动」关掉，移除存了密码的服务器，再删掉这个文件夹和上面的设置文件；
  服务器上先运行 ~/.kuai/*/kuaid --stop（结束终端、让常驻的程序退出），再删掉 ~/.kuai。
- 在服务器上看常驻的程序和终端：~/.kuai/*/kuaid --status；日志在 ~/.kuai/run/kuaid.log。
- 程序挪了位置以后，「开机时自动启动」要重新开一次（启动项里记的是原来的路径）。
- 看日志：在命令行里先设环境变量 FR_LOG=1，再把标准错误重定向到文件，比如
    set FR_LOG=1 && kuai.exe 2> log.txt
